# CIT 384 - HW8 Resume Site

**Name:** Daniel Isayan

**Class:** CIT384

Added sticky navigation without a list, links to each resume section, and a downloadable resume PDF. Added Font Awesome footer icons and used the CSS `background` shorthand to combine a section background image with an RGBA gradient overlay.

## GitHub Pages

[Website](https://killerpigwolf.github.io/comp484-hw8/)

**Hosting:** GitHub Pages, published from the main branch and repository root.

## Preview

Open index.html in a browser. No build step is needed. Google Fonts require internet access, with system font fallbacks. HW8 bundles Font Awesome Free 7.3.1 locally with its license so footer icons work offline.

## Content

Personal details and experience were supplied by Daniel Isayan: one year with ON DEMAND ELECTRICAL, 2.5 years in a busy coffee shop, a graduating CIT major, technical skills, English and Russian, and email/phone contact details. No school name or graduation date was supplied. The profile is an original initials graphic. For HW8, keep resume.pdf in sync with future content changes.
